# Municipal Councils E-Voting System in Saudi Arabia

## Overview
An academic team project for the Software Requirements Engineering course. The project explores a proposed electronic voting system for municipal council elections in Saudi Arabia, aiming to make voting more accessible, secure, and practical.

## Project Objectives
- Provide an online voting channel for eligible Saudi citizens.
- Improve voter participation.
- Protect voter identity and vote confidentiality.
- Support compliance with relevant election regulations.

## Main Deliverables
- Project background and goals
- Business rules
- Stakeholder map
- Context diagram
- Product use case diagram
- Use case scenarios
- Requirements traceability matrix
- Functional requirements
- Non-functional requirements

## Key System Concepts
- Voter identity authentication through GOV.SA (Nafath)
- One vote per eligible person
- Confidentiality of voter identity and votes
- Secure data transmission
- System availability and performance requirements
